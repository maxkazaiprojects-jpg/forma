# Дневник формы

Программа тренировок, дневная норма калорий и БЖУ, дневник питания и журнал тренировок.
Сайт: https://maxkazaiprojects-jpg.github.io/forma/

- `index.html` — весь сайт.
- `data.enc.json` — профиль, блюда, тренировки и вес в зашифрованном виде (AES-256-GCM, ключ через PBKDF2). Ключ передаётся один раз в ссылке `#k=…` и хранится только в браузере. Блюда вносит Claude по сообщениям в Telegram; записи, сделанные на сайте, хранятся в браузере, пока их не перенесут сюда.
